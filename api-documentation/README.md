# Directory

## Protected APIs

Require the authorization token, obtained through organization login.

### Charidy Account

## Organization / Donor Sign in

<mark style="color:blue;">`GET`</mark> `/orgarea/api/v1/signin`



## Get currency list

<mark style="color:blue;">`GET`</mark> `/orgarea/api/v1/account/currencies`



## Upload media / image to account

<mark style="color:green;">`POST`</mark> `orgarea/api/v1/account/media`



## Upload multiple media / images to account

<mark style="color:green;">`POST`</mark> `/orgarea/api/v1/account/media/many`



## Upload the documents into the account

<mark style="color:green;">`POST`</mark> `/orgarea/api/v1/account/documents`

### Donor account



## Get donor account information

<mark style="color:blue;">`GET`</mark> `/orgarea/api/v1/account/donor_account`



## Edit donor information

<mark style="color:purple;">`PATCH`</mark> `/orgarea/api/v1/account/donor_account`



## Create donor account

<mark style="color:green;">`POST`</mark> `/orgarea/api/v1/account/donor_account`
